# Runbook 1: #768 and #769, the fast plan judges a stale consumer like the resolver

> **For agentic workers:** read `LLM/02.768-773-runbook-common.md` first (models, branches,
> commits, STOP protocol). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `mrg --plan-world` names and repairs stale `:=` consumers the way
`emerge -puDN @world` does, except where the fast plan can repair a binding the resolver
only reports (a recorded `||` the tree can follow: owner decision 2026-11-22, see Global
constraints), and the resolver names a stale consumer that has no ebuild left.

**Architecture:** three product changes in three commits. S1: `portage-world` judges a
consumer outside the @world walk by its best visible ebuild, seeds the walk with the
rebuilds it finds, and lets the tree decide when a recorded text does not reduce. S2: a
recorded pin stops refusing a walked consumer whose tree ebuild accepts the new provider.
S3: the resolver's stale-pin scan pushes a refusal for a consumer with no ebuild instead of
staying silent.

**Tech stack:** Rust (`crates/portage-world`, `crates/portage-repo`, `crates/portuale`),
pytest (`../pmtest/pytests-contract-suite`), shell probes under `LLM/evidence/02.768/`.

**Spec:** `LLM/02.768-769-fast-plan-policy.opus.md` (called "the plan" below; `Q-A` to
`Q-J`, `S0` to `S5` and `STOP-1` to `STOP-4` are its labels).

    /// One scratch world for the consumer-outside-the-walk tests: `ebuilds`
    /// are added to a copy of the fixture tree, `installed` to the VDB, and
    /// `recorded` writes `(cpf, key, text)` into the installed entries.
    fn outside_world(
        world_atoms: &[&str],
        ebuilds: &[(&str, &str, &[(&str, &str)])],
        installed: &[(&str, &str)],
        recorded: &[(&str, &str, &str)],
    ) -> World {
        let tree = fixture_copy();
        for (cpv, slot, fields) in ebuilds {
            add_ebuild_fields(tree.path(), cpv, slot, fields);
        }
        testkit::analyse_fixture_with(world_atoms, installed, |o| {
            o.config_root = tree.path().to_path_buf();
            o.rebuilds = true;
            for (cpf, key, text) in recorded {
                std::fs::write(o.root.join("var/db/pkg/dev-libs").join(cpf).join(key), text)
                    .expect("recorded dependency");
            }
        })
    }

    const PROV_MOVES: [(&str, &str); 2] = [("dev-libs/w768prov-1", "0/1"), ("dev-libs/w768user-1", "0")];

    /// Charter property 5: a stale consumer the walk from `@world` does not
    /// reach is judged by its best visible ebuild, so the refusal names the
    /// recorded pin and the provider version, not "no visible ebuild".
    #[test]
    fn a_stale_consumer_outside_the_walk_is_judged_by_its_best_visible_ebuild() {
        let world = outside_world(
            &["dev-libs/w768prov"],
            &[
                ("dev-libs/w768prov-2", "0/2", &[]),
                ("dev-libs/w768user-1", "0", &[("RDEPEND", "=dev-libs/w768prov-1*")]),
            ],
            &PROV_MOVES,
            &[("w768user-1", "RDEPEND", "=dev-libs/w768prov-1* dev-libs/w768prov:0/1=")],
        );
        assert!(world.rebuilds.is_empty(), "{:?}", world.rebuilds);
        assert_eq!(
            world.refused,
            [crate::rebuild::RefusedBinding {
                consumer: "dev-libs/w768user".to_string(),
                atom: "=dev-libs/w768prov-1*".to_string(),
                provider: Some("dev-libs/w768prov-2".to_string()),
            }]
        );
    }

    /// Charter property 1 (PMS `dependencies.tex`, `sec:slot-dep`): a stale
    /// consumer outside the walk that nothing holds is rebuilt, and the
    /// rebuild is a row of the plan, not only a member of `rebuilds`.
    #[test]
    fn a_stale_consumer_outside_the_walk_is_rebuilt_when_nothing_holds_it() {
        let world = outside_world(
            &["dev-libs/w768prov"],
            &[
                ("dev-libs/w768prov-2", "0/2", &[]),
                ("dev-libs/w768user-1", "0", &[("RDEPEND", "dev-libs/w768prov:=")]),

            &[("w768user-1", "RDEPEND", "dev-libs/w768prov:0/1=")],
        );
        assert_eq!(world.rebuilds.iter().collect::<Vec<_>>(), ["dev-libs/w768user:0"]);
        assert!(world.refused.is_empty(), "{:?}", world.refused);
        let rows = world.ordered(&Order::Alpha);
        let row = rows.iter().find(|s| s.node() == "dev-libs/w768user:0");

    /// tree pins the old provider, the provider stays and the consumer is
    /// still a row.

    /// recorded only in `DEPEND` counts for a consumer the walk reached, and

        let ebuilds: [(&str, &str, &[(&str, &str)]); 2] = [
            ("dev-libs/w768prov-2", "0/2", &[]),

/// The chosen ebuild's tree atoms over `keys`, with `||` groups and USE
/// conditionals reduced the way the planner reduces them. `None` when the
/// metadata is unreadable or a text does not reduce.
fn tree_reduced_atoms(args: &TreeNamesProviderArgs<'_>, keys: &[&str]) -> Option<Vec<String>> {
    let pf = format!("{}-{}", args.package, args.chosen.version);
    let meta = portage_repo::repo_aux_metadata(&args.chosen.repo_location, args.category, &pf).ok()?;
    let use_flags: HashSet<String> = portage_repo::effective_use_flags(EffectiveUseFlagsArgs {
        config: args.config,
        iuse: &args.chosen.iuse,
        keywords: &args.chosen.keywords,
        candidate_str: &args.chosen.match_str(args.category, args.package),
        build_id: None,
        category: args.category,
        package: args.package,
    })
    .iter()
    .cloned()
    .collect();
    let mut out = Vec::new();

        out.extend(reduced_recorded_atoms(text, &use_flags, args.memos, args.config)?);
    }
    Some(out)
}
