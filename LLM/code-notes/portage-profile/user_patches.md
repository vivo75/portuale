# crates/portage-profile/src/user_patches.rs

## struct UserPatchSet
- Local user-patch sets (`/etc/portage/patches`), Portage's `UserPatches` (`lib/portage/package/ebuild/_config/UserPatches.py`). Loaded once in `resolve_config`; the resolver reads `digest`/`files` through `Config::user_patches` (backlog #509).
- Digest algorithm (verified byte-equal to host `userPatchDigest` on the S10 oracle tree, `LLM/evidence/2026-10-23-509/`, and to the upstream `MockUserPatches` NIST vectors pinned in `src/tests/user_patches.rs`): per-file sha256 hex of the `.diff`/`.patch` files matching the package, basenames sorted as bytes (`LC_ALL=C sort -z`), entries hashing to the empty-sha256 skipped, sha256 over the concatenated hex. Matches the shell `eapply_user` writer (`bin/phase-helpers.sh`: `total+="${hash}"`, sorted NUL list, `-s` non-empty test) — the oracle `--buildpkgonly` index entries equal the Python digests.
- Key matching, least to most specific (later overwrites same basenames): `cat/pn`, `cat/pn-ver`, `cat/pn:slot`, `cat/pn-ver:slot` (main slot only, `${SLOT%/*}`). Presence (`__contains__`) is any of the four dirs existing with at least one patch-suffixed file; `digest` is `""` when none match or every match is empty; `files` is the `cat/dir/file` union (including empties), which the `--verbose` tail sorts.
- `UserPatchSet::has` (#542) is the merge-time gate's first half: any of the four keys present, even all-empty (Portage `UserPatches.__contains__`, `Binpkg.py` `_unpack_metadata`'s `pkg not in settings._user_patches`). `digest` is `""` in exactly that case too, so the second half (`digest != index`) needs `has` to tell "no set" from "empty set" -- both warn, but for different reasons.
- Crash fix `7964f58e2` (bug 982999): a `patches` file, stray files directly under `patches/` or `patches/<cat>/`, and non-directory set paths are ignored (`is_dir` guards), never an error. Oracle shape 15 (`15-stray-k.*`).
- The `-r1` empty default (bug 984255, `bintree.py` `_pkgindex_*` defaults `"USER_PATCHES": ""`) lives on the read side (`Candidate.user_patches` defaults to `""`); an absent patches directory is `None`, whose digest is also `""`, so trust-without-patches needs no special case.
