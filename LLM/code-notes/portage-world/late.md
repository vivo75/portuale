# crates/portage-world/src/late.rs
The check of a fast plan's own order: which build atoms are not met when their row is built.

## fn late_build_needs (#772)
- Charter 2a (literal): a build dependency is installed before the package that needs it; a runtime one need only be there by the end. For each row and each build atom (a boot row skips the edges `Bootstrap::drops` removes) whose target slot has rows only after the requesting row, the atom is a need unless an earlier row meets it, an installed version meets it and no earlier row replaces that slot, or another `||` arm is met so the reduction drops the atom. A target with a row before the need, an atom no row aims at (unmatched, masked best) and a kept slot are left to the checker and the "not checked" line; the line "merged later" is never printed for an atom nothing merges.
- Moved binding: PMS `dependencies.tex:348-350` gives `:=` its binding meaning only as a `DEPEND` dependency. An installed provider meets such an atom only while the plan keeps its sub-slot; a plan that replaces it with another one later leaves the consumer's binding stale (`LateNeed::moved_binding`), which the literal checker cannot see. A `BDEPEND`-only `:=` is a plain match.
- `||`: `or_displaced` re-reduces each variable holding the atom with `use_reduce_flat_disjunctive`, the arms met at the row preferred and the atom's own arm as tie-break, so only a met arm can displace it. Lifted from the census (`LLM/evidence/02.771-772/before/census.patch`, which measured the same rules on the host, emptytree and bed plans: no late need on any of them).
- The path of a need is `row -> target -> ... -> row` along build edges (`order::build_path`), or none; the no-path wording is "no build cycle joins them, so the order itself is wrong" (shape `w764d*`, #771 not shipped).
- Census of the produced orders (before this change; `before/772-verdict.txt`): late edges whose target is a plan row were 327 met by an installed version (C1a: 8 host, 306 emptytree, 13 bed), 3 met through a displaced `||` arm (C5, emptytree), none moved a `:=` binding, none unmet. C1b is exercised only by the `w772d*` fixtures.
