## fn attr_display_field
- Column contract: `I` = `interactive` (`GraphEntry::interactive`); `N` = `new` (`r` for force-reinstall -- portuale has no `--emptytree`/`arg.force_reinstall` concept, so always `N` or space; a plain reinstall shows `R` at col 2, since Portage's `_get_installed_best` sets `replace=True` only when the exact cpv is already installed); `S` = `new_slot` (`R` for `replace` -- every portuale `Reinstall`); `f`/`F`/`g` = fetch-restrict satisfied / unsatisfied / remote binary (`g` needs `--getbinpkg`); `U` = `new_version` (in-slot change); `D` = downgrade; mask char from `gen_mask_str` (`GraphEntry::keyword_mask`) or a space.
- Portage's `set_pkg_info` fills the mask in only `if self.include_mask_str()` (`verbosity > 1`), and Portage's default `emerge -p` verbosity is *2* (`_DisplayConfig.__init__`: `--quiet and 1 or --verbose and 3 or 2`) -- so the column is present at plain `-p` *and* `-pv*, and absent (6 chars, not 7) only under `--quiet` (verbosity 1). `include_mask` carries that gate.
- Colours per Portage's `PkgAttrDisplay.__str__` (`green("N")`, `yellow("R")`, `turquoise("U")`, `blue("D")`, `colorize("WARN", "I")`, the `#`/`*`/`~` mask via `BAD`/`WARN`, …); a space is never coloured (`color::nc_len` recovers the width for `--columns` padding). `gen_mask_str`: `#`/`*` -> `BAD` (red), `~` -> `WARN` (yellow), no mark -> a space.
- Portage `PkgAttrDisplay.__str__` (`_emerge/resolver/output_helpers.py`): the fixed-width status field rendered inside the `[ebuild …]` bracket, exactly `[{pkg.type_name} {attr_display}]`. One column per attribute, a literal space where the attribute is absent, in this exact order: 0. `I` -- `interactive` (`GraphEntry::interactive`). 1. `N` -- `new`; `r` instead when `force_reinstall`. Portuale has no `--emptytree`/`arg.force_reinstall` concept, so always `N` or space here -- a plain reinstall shows `R` at col 2, see Portage `_get_installed_best`: `replace=True` is set only when the exact cpv is already installed. 2. `S` -- `new_slot`; `R` instead when `replace` (the cpv is already installed -- every one of portuale's `Reinstall` outcomes). 3. `f`/`F`/`g` -- fetch-restrict satisfied / unsatisfied / remote binary (`g` is out of scope, needs `--getbinpkg`). 4. `U` -- `new_version` (an in-slot version change -- `Upgrade`/`Downgrade`). 5. `D` -- `downgrade`. 6. the mask column -- the `#`/`~`/`*` char from `gen_mask_str` (`GraphEntry::keyword_mask`) or a space. Portage `set_pkg_info` fills it in only `if self.include_mask_str()` (`verbosity > 1`), and Portage default `emerge -p` verbosity is *2* (`_DisplayConfig.__init__`: `--quiet and 1 or --verbose and 3 or 2`) -- so the column is present at plain `-p` *and* `-pv`, and absent (the field is 6 chars, not 7) only under `--quiet` (verbosity 1). `include_mask` carries that gate. Each present letter is ANSI-coloured per Portage `PkgAttrDisplay.__str__` (`green("N")`, `yellow("R")`, `turquoise("U")`, `blue("D")`, `colorize("WARN", "I")`, the `#`/`*`/`~` mask via `BAD`/`WARN`, …) when `color.enabled`; a space is never coloured. When colour is off every call returns the bare char, so the field is exactly 7 visible columns either way (`color::nc_len` recovers that width for `--columns` padding).
- Portage `__str__` appends `self.mask` only `if self.mask is not None`, and `set_pkg_info` sets it only `if self.include_mask_str()` (`verbosity > 1`) -- true at Portage portage's default `emerge -p` verbosity of 2, absent under `--quiet` (verbosity 1).
