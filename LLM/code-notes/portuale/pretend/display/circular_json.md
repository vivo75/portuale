## fn render_circular_json
- Schema and key order, pinned from the captures: `cycles` (list of cycles, each a list of cpv strings; one rotation per member, Q6), `shortest_cycle` (list of `{parent, child, priority, affecting_use}`), `solutions` (list of `{package, use_changes: [{flag: bool}]}`), `test_dep_parents`, `masked_alternatives` (list of `{package, alternatives}`), `search_truncated`, `max_affecting_use` (integer). Every list is sorted by cpv in Portage except `cycles` and `shortest_cycle` (graph order) and, in portuale, the flags of one `use_changes` object (Portage: hash order, Q6).
- Format is Python's `json.dumps(report, indent=2)` plus a newline: two-space indent, `": "` separators, `,` at line end, empty containers inline (`[]`), `true`/`false`, non-ASCII escaped as `\uXXXX` (`ensure_ascii`). The small `Json` enum in the file exists only for this; `pretend/json.rs` is the flat `--json` merge-list writer and does not escape non-ASCII.
- Streams (host captures 01-54): the document is on stdout, stderr is empty (except the `!!! Invalid PORTAGE_CIRCULAR_MAX_USE_FLAGS` warning), rc 1. The text report's `display(handler.merge_list)` and the error blocks are not printed: no `[nomerge]` rows, no `Total:`. The resolution preamble (`These are the packages that would be merged, in order:` / `in reverse order:` under `--tree`, `Calculating dependencies ... done!`, the timing line) precedes the document on stdout as for any `--pretend` resolve; portuale cuts the wall-clock seconds like everywhere else. `--quiet` drops the preamble, `--color y` colours only the preamble, never the document.
- Values: `=text`, `=True` and the bare option select the text report (S4 parser, Portage `choices=("True", "text", "json")`); `=none` is not a choice in Portage 3.0.83-r1 (rc 2, argparse error, same as portuale's S4 parser). The bare option followed by a package atom keeps the atom (`insert_optional_args`).

## Wiring
- `print_circular_block` (`circular.rs`) dispatches on `PrintCircularBlockArgs::format`; the json arm builds `portage_repo::build_cycle_report` and prints the document. Both call sites (`problem_reports.rs` abort path, `final_gates.rs` non-abort path) pass `opts.circular_deps_report`.
- `circular_report_shown` (`problem_reports.rs`) says when the block prints at all (a hard cycle, and the resolve did not abort for another reason first); `pretend/mod.rs` uses it with `format == json` to suppress the merge list (`show_merge_list = false`, `display_list_suppressed`) and to print the preamble. Without `--pretend` the existing non-pretend header rules apply.
- `GraphResult::report_cycles` (`resolve/assemble.rs`, `solver_bridge.rs` `bridge_circular_display`) carries the cycle list.
