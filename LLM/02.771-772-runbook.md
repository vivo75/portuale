# Runbook 4: #771 and #772, the fast plan's cycle cut and its cycle line

> **For agentic workers:** read `LLM/02.768-773-runbook-common.md` first (models, branches,
> commits, STOP protocol). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `mrg --plan-world --sort depend` (a) cuts a cycle that is uncuttable only
because of the build-used rule at its first runtime-only edge (#771), and (b) prints a
build-cycle line only when the order it produced really builds a package before a build
dependency is there, on a path that is real (#772).

**Architecture:** #771 is a three-line fallback in `cycle_cut`, shipped only if a
measurement on the host plan and on the bed plan shows it moves no bed row and adds no
literal `build-order` failure. #772 replaces the Tarjan member list `plan_world.rs` prints
with a check of the final rows: for each row, each build atom whose target is merged
later and that nothing installed or earlier meets is a "late need", printed with the
shortest real build path back.

**Tech stack:** Rust (`crates/portage-world/src/{order.rs,lib.rs,bootstrap.rs}`,
`crates/portuale/src/plan_world.rs`), pytest (`../pmtest/pytests-contract-suite/test_plan_world.py`),
podman for the bed plan.

**Spec:** `LLM/02.771-772-build-cycle-cut.opus.md` ("the plan"; classes `C1a` … `U`, `Q1`
to `Q7`, `S0` to `S4`, `STOP-0` to `STOP-4` are its labels). Read its §0.3 table before
Task 3 and its S2.3 before Task 7.
