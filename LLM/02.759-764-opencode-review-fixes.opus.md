## S1 — #759 bootstrap correctness (portage-use-reduce, portage-repo, portuale emerge_build)

1. Forced flag. Red test in `crates/portage-repo/src/tests/bootstrap.rs`:
   the w753-style pair with the guard flag in the profile's `use.force` (or
   `package.use.force`) for the boot package → no bootstrap, the cycle is
   reported as today. Fix: candidate flags exclude the boot entry's forced
   set (`forced_or_masked_flags`, already computed for display in
   `boot_display_inputs`); when the best candidate is excluded, the next one
   is tried (`bootstrap_reduction` takes an eligibility predicate instead of
   returning a single fixed answer). Command:
   `cargo test --release -p portage-repo bootstrap` → new test green.
2. REQUIRED_USE preference (never refusal). Red test: two candidate flags
   break the same cycle; removing the lexicographically first violates the
   boot package's `REQUIRED_USE`, the second does not → the second is chosen.
   With only a violating candidate, the bootstrap still happens.
3. Removal only. Test that the boot row's USE is a strict subset of the
   declared USE for every bootstrap the tests build (assert in the shared
   test helper), and a unit test that a `!flag?` guard never yields `flag`
   as a candidate.
4. `!flag?` build arm. When removing `flag` switches on a `!flag?` arm that
   contributes a build-time atom to the boot package, refuse the bootstrap
   (the boot row could not carry the new dependency in order). Red test with
   `DEPEND="!useboh? ( dev-libs/x )"`.
5. `--resume`. Red test in `crates/portuale/src/emerge_build/tests/` (resume
   tests): a saved list holding boot + middle + definitive resumes with the
   first row still built with the reduced USE. Investigate first how the
   resume list is stored (`emerge_build/resume.rs`, `mtimedb.rs`; #585 keeps
   the mtimedb in Portage's shape). If the marker cannot be stored without
   breaking that shape, STOP and report the options to the reviewer before
   writing code.
6. Interrupted run message. Red test: the middle row fails after the boot row
   merged → the failure summary (`emerge_build/failure.rs`) prints one line
   naming the package installed with reduced USE, the removed flag, and the
   command that restores it (`emerge --oneshot =<cat>/<pf>`). Charter 5.
7. Simplify the guard machinery: replace `conditional_guards`,
   `edge_drops_without_flag` and `guard_map` with one function that evaluates
   the dependency string twice (declared USE, declared − flag) with the
   existing `use_reduce` and compares the atoms per `cp`; `boot_row`'s filter
   uses the same function. Keep every existing bootstrap test green
   unchanged. Also: `graph_view_reaches` builds `merge_bound_index` once,
   `bootstrap_reduction` uses `min_by_key`, drop the
   `#[allow(clippy::too_many_arguments)]` that clippy does not need.
8. Comments in the touched files follow the rule (history → existing
   `LLM/code-notes/portage-repo/resolve/bootstrap.md` and
