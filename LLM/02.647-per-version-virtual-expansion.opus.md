## Review Focus

- Per-version, not latest-version: the expansion must consider every matching tree version's RDEPEND (including the `1.700.0`/`3.240.0` `=perl-5.44*` conjunctions), not just the newest — a latest-only port passes M6b/M5 today and rots tomorrow.
- The conjunction extras (`perl:=`, `!<`, `!>`) ride the SAME expansion; a port that expands pure-`||` versions but drops versions with extras re-trips on the real tree.
- The #646 no-upgrade tie and the p02/p03 shapes stay exactly green: with no co-scheduled upgrade the conjunction + pin still holds the tie (no new merges from expansion alone).
- New fixture ebuilds only (collision-checked names, real md5-cache entries — memory `md5-cache-validation`); existing fixtures untouched; vdb records at the real versions.
- MUST NOT use `@world --update --deep` in any new CASES row or Rust request: M4/M5b prove that shape upgrades the virtual instead of falling through — pin that behavior as not-the-cell, don't reshape it.
