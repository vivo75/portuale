## 0. Premise and what grounding found

### 0.1 The code (read)

- `Memos::branch_preference_uncached` (`crates/portage-world/src/lib.rs:319-351`) ranks one `||`
  arm. Its "installed" test is **per package, not per slot** (`:330-333`):
  `self.installed.contains(&format!("{}/{}", a.category, a.package))`. A per-slot map already
  exists and is unused here: `Memos::installed_slots` (`:112-113`, filled at `:150-162`, main slot
  only, sub-slot cut off).
- Plan mode (`newest_slot`, set from `opts.rebuilds`, `crates/portuale/src/plan_world.rs:35`)
  adds the ranks `BestVisibleInstalled` > `BestVisibleAvailable` > `Installed` > `Available`
  (`crates/portage-use-reduce/src/lib.rs:824-863`). For
  `|| ( dev-lang/python:3.15 dev-lang/python:3.14 … )` with only `python-3.14.10` installed:
  arm `:3.15` = best visible of slot 3.15 matches **and** cp `dev-lang/python` installed →
  `BestVisibleInstalled`; arm `:3.14` = the same rank. Tie → the first listed arm wins
  (`tie_break` `first`, `lib.rs:384-385`). So the plan takes `:3.15`. **This is derived from
  source; S0.2 confirms it.**
- The late-need check already copes: `Facts::or_displaced` (`crates/portage-world/src/late.rs:252-317`)
  re-reduces the group with the arms met at the row preferred, so the three C5 edges print no
  line. No health property is broken today (#772 verdict: 0 build-order findings on the emptytree
  plan).
