**Goal:** `portuale vdb mount --rw KIND:PATH MOUNTPOINT` lets real Portage 3.0.82.2 `emerge`/`ebuild` merge, replace and unmerge through a mount over `sqlite`/`redb`, with every change stored in the database.

**Architecture:** A new pure module `rust/portuale/src/vdb_rw.rs` (`RwView`) wraps the existing read-only `vdb_view::View` and adds three layers: volatile names in memory (lock files, hardlinks, empty categories), staged `-MERGING-<pf>` entries on scratch disk published with one `insert_entry` transaction at the rename, and live-entry edits published as `replace_file` / `delete_entry`. `vdb_fuse.rs` stays a thin adapter that routes write callbacks to `RwView` when mounted `--rw`. All decisions are unit tested without a mount by replaying operation scripts against `RwView` and against a plain directory, then comparing with `portage_vdb::verify`.

**Tech Stack:** Rust 2024 workspace in `rust/`, `fuser` (no libfuse), `portage-vdb` (`InstalledDb`, `WriteTxn`, `EntryImage`, `verify`), sqlite/redb features; pmtest L1 bed (podman, bash, python) for the end-to-end gate.

**Spec:** [`docs/superpowers/specs/2026-10-05-rw-fuse-vdb-design.md`](superpowers/specs/2026-10-05-rw-fuse-vdb-design.md). Read it first; section numbers below (§N) refer to it. Parent design: [`feat-157-authoritative-vdb-database.md`](feat-157-authoritative-vdb-database.md) D2.

    /// (cat, name) -> file; hardlinks are two keys with the same ino.
    vol: BTreeMap<(String, String), u64>,
    vol_files: HashMap<u64, VolFile>,
    /// Categories that exist only because of mkdir (no entry yet).

    handles: HashMap<u64, RwHandle>,          // overlay handles; View handles pass through

fn is_volatile_name(name: &str) -> bool {

Rules: `mkdir` at root of a name that is not an existing category → `vol_cats`; `rmdir` of a category → allowed only when the category has no live entry, no staged dir and no volatile file (`NotEmpty` otherwise). `create`/`link`/`unlink` of a volatile name inside a category → `vol`. - [ ] **Step 4: wire `--rw`.** `vdb_cmd.rs` `mount`: parse `--rw` and `--root ROOT` (default `/`); refuse `--rw` with `files:` ("files:ROOT is already writable on disk"). `vdb_fuse.rs`: `enum Mode { Ro(View), Rw(RwView) }`; in `Rw` the write callbacks (`create`, `mkdir`, `unlink`, `rmdir`, `rename`, `link`, `write`, `setattr`, `release`) call `RwView` and map `ViewError::errno()`; `getlk`/`setlk` stay unimplemented (kernel-local POSIX locks); mount options drop `MountOption::RO` in `Rw`. - [ ] **Step 2: implement staging.** `RwState.staged: BTreeMap<(String /*cat*/, String /*dir*/), Staged>` with `Staged { ino: u64, path: PathBuf /*scratch*/, mode: u32, mtime_ns: i128 }`. - [ ] **Step 3: implement publish** (`rename` of a staged dir to `<pf>` in the same category):

```rust
fn publish_staged(&self, st: &mut RwState, cat: &str, dir: &str, pf: &str) -> Res<()> {
    let s = st.staged.get(&(cat.into(), dir.into())).ok_or(ViewError::NoEnt)?;
    let mut files = Vec::new();
    for e in std::fs::read_dir(&s.path).map_err(io)? {
        let e = e.map_err(io)?;
        let md = e.metadata().map_err(io)?;
        if !md.is_file() { return Err(ViewError::Perm); }
        let name = e.file_name().into_string().map_err(|_| ViewError::Perm)?;
        files.push(EntryFile {
            meta: FileMeta { name, mode: md.mode(), mtime_ns: mtime_ns_of(&md), len: md.len() },
            data: std::fs::read(e.path()).map_err(io)?,
        });
    }
    files.sort_by(|a, b| a.meta.name.cmp(&b.meta.name));
    let metadata = files.iter().find(|f| f.meta.name == "metadata").map(|f| f.data.as_slice());
    let image = EntryImage {
        key: EntryKey::new(cat, pf),
        files: files.clone(),
        dir_mode: s.mode & 0o7777,
        dir_mtime_ns: s.mtime_ns,
        metadata_stamp: stamp_state(metadata, s.mtime_ns),
    };
    let counter = files.iter().find(|f| f.meta.name == "COUNTER")
        .and_then(|f| std::str::from_utf8(&f.data).ok()?.trim().parse::<i64>().ok());
    let mut txn = self.db.begin_write()?;
    txn.insert_entry(&image)?;
    if let Some(c) = counter {
        if self.db.counter()?.is_none_or(|cur| cur.0 < c) { txn.set_counter(Counter(c))?; }
    }
    txn.commit()?;                                  // EIO on failure, scratch kept
    let _ = std::fs::remove_dir_all(&s.path);
    st.staged.remove(&(cat.into(), dir.into()));
    Ok(())
}
```
