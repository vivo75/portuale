## What was built

- `rust/portuale/build.rs` embeds `bin/` and the new tracked `cnf/sets/portage.conf`
  (a vendored copy of upstream's file, same ref as `3rdparty/repos.toml`'s
  `[portage]`) as a sorted table; modes normalised (0o755 if any exec bit,
  else 0o644), symlinks kept, no mtimes. No new crate.
- `rust/portuale/src/embedded_runtime.rs`: `ENTRIES`, `file()`, `extract()`.
- `ebuild_phases.rs`: `resolve_bin_dir(override, build_root, has_embedded)` →
  `BinSource::{Dir, Embedded}`; order `$PORTUALE_BIN_DIR` (set-but-wrong is an
  error, never a fallthrough) > build tree `bin/` > embedded copy extracted to
  `$TMPDIR/portuale-rt.<pid>/bin`; one `register_cleanup` `atexit` owner for the
  extracted tree and the #88 overlay; `package_sets_conf()` (checkout file
  first, embedded otherwise) used by `defined_set_names`.

- Release binary 21,211,160 → 21,522,568 bytes (+311,408; `bin/` is 292 KB).
