## `!!!` placement rule

`porttree.py:1156,1216-1225`: `cp_list` collects ebuilds from **all** repos
first, then — only when the category is unlisted **and** ebuilds exist —
prints `\n!!! '<cp>' has a category that is not listed in
<PORTAGE_CONFIGROOT>etc/portage/categories\n` and returns `[]`. The result
is cached per cp (`xcache`), so one emerge process prints it **once per cp**
no matter how many lookups name it. No ebuilds on disk → no `!!!` (plain
miss). Traversal (`cp_all`, `--search`, `--regen`) and short-name expansion
(`cpv_expand`/`_dep_expand` iterate `db.categories`) never print it.

## Quirks recorded in `LLM/portage-quirks.md`

- `categories` files are one-category-per-line in effect: `grabfile`
  rejoins each line, so `a b` on one line matches `_category_re` never and
  lists neither.
- The `!!!` names `etc/portage/categories` though the set is a union of
  every repo's `profiles/categories` plus that file.
