**Goal:** make the bed cell `MULTI_deep-update-world` match Portage on three
things: the `r` flag on `dev-lang/perl-5.44.0`, the `The following packages are
causing rebuilds:` block, and the merge order (first divergence at #10).

**Architecture (verified against `3rdparty/portage` 3.0.83 and this tree,
2026-10-28):** Portage marks a merge row `r` when a force-reinstall internal set
arg matches it (`lib/_emerge/resolver/output.py:812-816`, via
`_iter_atoms_for_pkg`, `depgraph.py:4988`). The set args are built by
`_gen_reinstall_sets` (`depgraph.py:5473-5497`) as
`__auto_reinstall__` / `__auto_slot_operator_replace_installed__` with
`force_reinstall=True`, and reach `_initial_arg_list`. The rebuild block is
`_show_abi_rebuild_info` (`depgraph.py:1146-1159`) over `_forced_rebuilds`,
filled by `_compute_abi_rebuild_info` (`depgraph.py:931-1145`), which seeds
**from those same force-reinstall args** (`depgraph.py:940-950`). So the `r`
flag and the block do share one seed in Portage; whether portuale's gap is that
seed or the display filter is Task 0b's question, not an assumption.

Portuale splits what Portage keeps in one set, and this split is the whole
difficulty:

| field | what it is | read by |
|---|---|---|
| `slot_operator_replace_installed` (`backtrack_params.rs:361-364`) | the rebuild set; also the display scan's `already` input (`assemble.rs:38`) | `PORTUALE_BT_TRACE` (`feedback/mod.rs:158-169`) |
| `probe_replaced` (`backtrack_params.rs:367-370`) | the members the built-parent update probe filed; **only these render `r`** | `assemble.rs:295` → `result.slot_operator_replaced` → `pretend/mod.rs:495` |
| `result.abi_rebuilds` | the `(provider_cpv, consumer_cpv)` block pairs | `final_gates.rs:41-96`; also force-reinstall tagging, `pretend/mod.rs:486,866-905` |

The block pairs are computed post-walk by `slot_operator_rebuild_scan`
(`slot_operator/rebuild_scan.rs`), assembled in `resolve/assemble.rs:18-66`
plus `slot_conflict_abi_display_pairs` (`:54-60`). The probe's child filing
exists at `installed_parent_update_probe.rs:189-190` (gated on
`child_has_slot_update`); `:119-121` is the unrelated `arg_pins_installed` gate.

**Tech stack:** Rust (`portage-repo` resolver, `portuale` pretend renderer),
pmtest bed (`differential-test-bed/run/l0-resolver.sh`), pytest contract suite.

**Spec:** backlog #601 (`LLM/backlog-tasks.md:899`), owner ruling in

Read-only findings added 2026-10-28:

- The order divergence at #10 is one swap: Portage lists `net-libs/nghttp3`
  before `sys-libs/libseccomp`, portuale the other way round. It looks like a
  tie-break, probably independent of the display gap.
- **The set sizes are 35 (Portage) and 34 (portuale), not 36/34.**
  `captures/portage-forced-reinstall-atoms.txt` holds 35 `atom:` lines
  including `dev-lang/perl:0`; the trace's 34 are identical minus that one
  (`captures/portuale-bt-trace.txt`, try 26). Always count, do not add.
- **The 34 are the rebuild set, not the display set.** The trace prints
  `slot_operator_replace_installed`; `r` reads `probe_replaced`
  (see the table above). Portage keeps one slot-operator set where portuale
  keeps two, so "identical except perl" says nothing yet about the `r` half.
- **`captures/portuale-final-forced-atoms-empty.txt` is not a measurement of
  any internal set.** `pretend/mod.rs:637` passes `opts.reinstall_atoms` — the
  `--reinstall-atoms` CLI option (`pretend/args.rs:778-792`) — into
  `print_resolver_debug`, while Portage's counterpart
  (`depgraph.py:940-950`) prints the internal force-reinstall set args. Its
  emptiness is expected either way.
- **The fixture machinery already works.** `p589bpull` reproduces the exact
  shape: Portage prints `[ebuild  r  U  ] dev-libs/p589bprov-5.44` **and** the
  block (`r5/captures/puD-p589bpull-portage.txt:32,41`), and
  `test_emerge_pretend_contract.py:36680-36736` (`_598_expect`/`_598_check`)
  pins both for `p569pull` and `p589bpull`; confirmed green 2026-10-28
  (`pytest -k test_598_update_deep_rebuilds_the_walked_installed_virtual` →
  2 passed). So the cell's gap is **shape-specific**, not missing machinery,
  and a same-shape `X:0/1 -> X:0/2` fixture would be green.
- `portuale-modes/_world.json.txt` in the run directory is a different run
  (157 entries, 0 restarts, empty `abi_rebuilds`), not this cell; it cannot
  separate H1 from H2.
