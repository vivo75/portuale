## 2. Concurrency model (≤ 3 operations, one writer)

Same rules as the 2026-10-19 batch plan §2, carried over unchanged:

- **Slot W (writer):** `gemini-argon` on portuale source, tests, notes. One slice at a time, ending clean (fmt, clippy, tests green) so the executor can commit.
- **Slot O (oracle/fixtures):** `gemini-probe-capture`, `gemini-fixture-smith` (pmtest fixture files only), `gemini-argon-ro` reviews. Probes use the **frozen binary copy**, never `target/release`.
- **Slot B (bed/suite):** `gemini-bed-runner` on the frozen copy, one run at a time; or a full local suite run (`gemini-verify-pass`), never both beside a building writer.
- **Gate window:** full pmtest suite + `cargo test` run when slot W is idle. Slots O/B may continue on the frozen copy during a gate window; slot W waits.
- **Frozen binary:** `cp -p target/release/portuale /var/tmp/bedbin/portuale` after the writer's slice is green and before the bed/probe runs that gate it; registry entry `portuale-bed` (`PMTEST_PM=portuale-bed PMTEST_NO_BUILD=1`). A bed run starts only after the copy for that slice exists.
- **Cargo:** every cargo command through `flock /var/tmp/cargo-portuale.lock`. A spurious failure while another agent builds is re-run once before it is believed.
- **Launch:** `LLM/tools/scope/oc.sh <slug> <agent> <workdir> <brief.md> <log>`, 60 s stagger, `timeout 7200000`, one persistent Monitor per agent, stop with `ocstop.sh`; never `pkill`/`pgrep -f`; never edit a running script.
- **Sub-agents:** every brief says "you may delegate only to read-only agents (`gemini-argon-ro`, `codebase-memory*`); never to an agent that can write."
- **Read-only agents cannot write files** (executor captures their findings into the evidence file).
- **Disk:** `/var/tmp` is tmpfs (~40 G shared); clean `/var/tmp/bedbin`, staging dirs at the end of each wave; never `/dev/shm`.
- **Commits stay with the executor**, per verified slice (pmtest first).
