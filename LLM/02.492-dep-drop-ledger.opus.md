**Goal:** a dependency token the resolver skips can no longer vanish silently: every
`parse_atom` on a dependency token either goes through one counting helper or carries a
per-site `drop-ok:` justification, and a test fails otherwise.

**Architecture:** (1) `parse_dep_atom(token, site)` in `portage-repo/src/globals.rs`
generalises today's `note_unparsed_dep_token`, keeping a per-site count. (2) A Rust
source-scan test enforces the per-site allowlist (the `// drop-ok: <reason>` comment *is*
the allowlist; it cannot go stale because it sits on the line). (3) The existing pmtest
invariant (`check_unparsed_dep_tokens`) keeps asserting zero, now with per-site detail.
(4) A cut registry script catches stale/orphan scope cuts in docs.

**Spec:** the approved proposal in this conversation (`LLM/recurring-issues.md` §1, §5).
Owner decisions: allowlist is **per site** (not per case).

## Deviations from the approved proposal (surfacing, not hiding)

- The proposal sketched a `DropReason` enum with `Intentional` variants that are also
  counted. Counting intentional drops (blockers, `package.provided`) would add noise to
  a number that must be exactly 0. This plan keeps only the *unparsed* count as the
  asserted metric; intentional drops are marked in source with `drop-ok:` and enforced by
  the lint. Same guarantee, less machinery. Re-open if you want the enum anyway.
- `PORTUALE_DROP_LEDGER=path` file output is dropped (YAGNI): the existing
  `PORTUALE_REPORT_UNPARSED_DEP_TOKENS` stderr report gains a per-site breakdown instead.

```rust
use std::{fs, path::Path};

fn scan(dir: &Path, out: &mut Vec<String>) {
    for e in fs::read_dir(dir).unwrap() {
        let p = e.unwrap().path();
        if p.is_dir() {
            if p.file_name().unwrap() != "tests" { scan(&p, out); }
        } else if p.extension().is_some_and(|x| x == "rs")
            && !p.file_name().unwrap().to_str().unwrap().contains("tests")
        {
            let text = fs::read_to_string(&p).unwrap();
            let lines: Vec<&str> = text.lines().collect();
            for (i, l) in lines.iter().enumerate() {
                if l.contains("portage_dep::parse_atom(") && !l.trim_start().starts_with("//") {
                    let ok = |s: &str| s.split("drop-ok:").nth(1).is_some_and(|r| !r.trim().is_empty());
                    if !(ok(l) || (i > 0 && ok(lines[i - 1]))) {
                        out.push(format!("{}:{}", p.display(), i + 1));
                    }
                }
            }
        }
    }
}

#[test]
fn every_dep_atom_parse_is_counted_or_justified() {
    let root = Path::new(env!("CARGO_MANIFEST_DIR")).join("src");
    let mut bad = Vec::new();
    for d in ["resolve", "slot_operator", "merge_order"] { scan(&root.join(d), &mut bad); }
    // solver_bridge.rs: scan the single file the same way (factor `scan_file`).
    assert!(bad.is_empty(), "unmarked parse_atom sites:\n{}", bad.join("\n"));
}
```
