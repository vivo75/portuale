# Plan 06.443 — record and compare terminal sessions (asciinema)

Status: done 2026-10-20 (branch tests-speed; pmtest scripts/cast_*.py). Residues #452, #453.
answers of 2026-10-20 are in the entry (pty must behave like a terminal;
record short/pretend cells; timing is a report, never a gate).

## 0. Findings that shape the plan

- `asciinema 3.2.0` (Rust) is installed on the host. `asciinema rec --headless
  --overwrite -q -c '<cmd>' out.cast` runs without a controlling terminal and
  writes asciicast v3 (header line + `[delta, "o"|"x", data]` events; the
  delta is relative to the previous event; `"x"` is the exit status). Verified
  with a two-line printf/sleep command.
- The contract suite already runs Portage's own `emerge` against the same
  fixtures (`PMTEST_PM=portage`, registry entry `portage`), with
  `fixture_env` (`PORTAGE_CONFIGROOT`, `ROOT`, `PORTAGE_RUNNING_ROOT`,
  `DISTDIR`). The recorder reuses exactly that env; no new oracle.
- Under a pty stdout and stderr are one stream, so asciicast shows the real
  interleaving, which the byte-compare suites (separate pipes) cannot.

## 1. Slices

- **C1 — recorder.** `pmtest/scripts/cast_record.py`: run an argv under
  `asciinema rec --headless` with a fixed tty size (120x40) and the given env,
  return the cast path and exit code. Stdlib only.
- **C2 — comparer.** `pmtest/scripts/cast_compare.py`: parse v3; join events
  into absolute times; normalise (ANSI-safe: keep escapes, strip temp paths,
  PIDs, durations, the cast timestamp and env); compare (1) the full text
  stream (Portage vs portuale, after normalisation), (2) the *chunking*: the
  ordered list of output events with their sizes (a progress line printed
  piecemeal vs in one write), (3) timing as a report: per event the
  elapsed-time ratio, flagged only above a generous tolerance, never failing.
  Exit status 0 always for timing; non-zero only if text differs when asked
  with `--strict-text`.
- **C3 — cells and report.** `pmtest/scripts/cast_cells.py`: a short list of
  pretend cells (taken from `CASES`, chosen for varied output: plain merge
  list, blocker, masked abort, autounmask suggestion, `--tree`, `--verbose`
  USE flags) run under both PMs, writes `<out>/<cell>.{portage,portuale}.cast`
  and one `report.md`. Default out dir `/var/tmp/casts`, never `/dev/shm`.
- **C4 — tests and docs.** `pytests-contract-suite/test_cast_tools.py`: unit
  tests of the comparer on synthetic casts (identical, text diff, same text
  different chunking, timing-only diff reported but not failing, path
  normalisation, truncated file), plus one smoke test that records
  `printf` and parses it (skipped when asciinema is missing). Docs:
  `pmtest/USAGE.AGENTS.md` paragraph, `what-this-proves.md` entry with the
  live report, backlog #443 marked DONE with residues.
