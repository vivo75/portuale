> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** done 2026-10-30 (Tasks 0-3, backlog #635; branch `slice/635-pid-init` in both repos — portuale `0554fa96`..`ca8ab480` plus the docs-only close-out commit; pmtest clean with no commit, no pretend-output change; no new residue)

**Goal:** Demoted `pid-sandbox` phases run as PID 1 of their own pid namespace with a namespace-local `/proc`, via a fork-and-reap dance inside the demotion `pre_exec` — restoring the namespace #630 had to drop as fatal, without any helper binary or re-exec.

**Architecture:** The demoted `pre_exec` (still root, post-`unshare`) forks once more: the middle process owns the session, forwards signals via `sigtimedwait` + `waitpid(WNOHANG)` polling (stack-local state — no process-global handler slot to race under parallel jobs), and reaps the grandchild with Portage's re-raise semantics; the grandchild — PID 1 of the new ns — remounts `/proc`, sets the hostname (not set: the middle does it pre-fork — `sethostname` is namespace-wide), unblocks the inherited signal mask, demotes to `portage:portage`, and execs the phase (the middle never returns from `pre_exec`). Demoted+pid spawns use `ParentGroup` placement so `spawn_trackable` adds no second `setsid` hook (with `NewSession` the chained hook would `setsid` the grandchild out of the middle's group and make a group-kill miss the phase). Pure flag/message code stays untouched; only the fork/reap block is new.

**Tech Stack:** Rust 2024 (`crates/portuale`), Portage 3.0.83 (`3rdparty/portage`, `bin/pid-ns-init` on host at `/usr/lib/portage/python3.14/pid-ns-init`), pmtest contract suite (`../pmtest`).

**Spec:** `LLM/backlog-tasks.md` #635, argued from `3rdparty/portage/lib/portage/package/ebuild/doebuild.py` (droppriv keywords), `lib/portage/process.py:1111-1145` (pid re-exec via `pid-ns-init`: demote-then-exec as init, setsid, signal forwarding by pid, reap-to-status), host `pid-ns-init:36-42,45-64,72-149` (forwarder shape, `preexec_fn` demote order, wait loop, re-raise), and `LLM/evidence/2026-10-30-630/task-2-pid-gap.log` (the ENOMEM proof this slice must turn green).
