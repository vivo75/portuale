# Runbook 2: #770, `--solver=pubgrub` rebuilds a walked stale consumer

> **For agentic workers:** read `LLM/02.768-773-runbook-common.md` first (models, branches,
> commits, STOP protocol). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** on root `pull`, `emerge --pretend -uDN --solver=pubgrub @world` prints
`[ebuild  rR    ] dev-libs/p569virt-1` and its "causes rebuilds for:" pair, as the default
solver does.

**Architecture:** the pubgrub bridge runs the shared slot-operator scan with an empty
`walked_installed` set, so an installed consumer the solve walked gets no edge. The fix
computes that set from the solution's `parents` map (installed packages below a package
the plan merges) and passes it to the scan. Nothing else changes: no new text, no change
to the default solver.

**Tech stack:** Rust (`crates/portage-repo/src/solver_bridge.rs`,
`crates/portage-repo/src/slot_operator/eliminate.rs`), pytest
(`../pmtest/pytests-contract-suite/test_plan_world.py`).

**Spec:** `LLM/02.770-pubgrub-walked-stale-rebuild.opus.md` ("the plan"; `H1` to `H5`,
`Q1` to `Q5`, `S0` to `S4`, `STOP-0` to `STOP-4` are its labels).

    /// A scratch root with the root-`pull` shape: `p569prov-5.42` installed,
    /// `p569virt-1` installed with `recorded` as its RDEPEND, and optionally a
    /// second installed hop `p770mid-1` between a merged package and the virtual.
    fn pg770_root(name: &str, recorded: &str) -> std::path::PathBuf {
        let dir = portage_util::TempDir::new(name);
        let _ = std::fs::remove_dir_all(&dir);
        let mk = |pf: &str, files: &[(&str, &str)]| {
            let d = dir.join("var/db/pkg/dev-libs").join(pf);
            std::fs::create_dir_all(&d).unwrap();
            s6_write_files(&d, files);
        };
        let base = [("CATEGORY", "dev-libs\n"), ("EAPI", "8\n"), ("repository", "testrepo\n")];
        mk("p569prov-5.42", &[base[0], base[1], base[2], ("SLOT", "0/5.42\n")]);
        mk("p569virt-1", &[base[0], base[1], base[2], ("SLOT", "0\n"), ("RDEPEND", recorded)]);
        dir.to_path_buf()
    }

    /// The pubgrub result for `-uD[N] dev-libs/p569pull` on `root`, seeded like
    /// the command line seeds a world update (selected, profile and system
    /// packages; here the one world atom is equivalent).
    fn pg770_solve(root: &std::path::Path, update: bool) -> super::super::GraphResult {
        let mut req = fixture_request(&["dev-libs/p569pull"]);
        req.root = root.to_path_buf();
        req.solver = super::super::SolverKind::PubGrub;
        req.rebuild_if_new_slot = true;
        req.update = update;
        req.deep = super::super::Deep::Unlimited;
        req.config.complete_seed_atoms = vec!["dev-libs/p569pull".to_string()];
        super::super::active_resolver_for(super::super::SolverKind::PubGrub)
            .resolve(&req)
            .expect("resolves")
    }

    fn pg770_reinstalls(result: &super::super::GraphResult, package: &str) -> bool {
        result.entries.iter().any(|e| {
            e.package == package && matches!(e.outcome, super::super::PretendOutcome::Reinstall { .. })
        })
    }

    /// PMS `sec:slot-dep`, charter property 1: the plan merges `p569pull-2`,
    /// which moves `p569prov` to 5.44; the installed `p569virt-1` the solve
    /// walked below it recorded `:0/5.42=`, so the bridge schedules its rebuild.
    #[test]
    fn pg770_bridge_rebuilds_the_walked_installed_consumer() {
        let root = pg770_root("portage-bridge-pg770-a", "dev-libs/p569prov:0/5.42=\n");
        let result = pg770_solve(&root, true);
        assert!(pg770_reinstalls(&result, "p569virt"), "{:?}", pg34_plan(&result));
        assert!(

            "{:?}",
            result.abi_rebuilds
        );
        let _ = std::fs::remove_dir_all(&root);
    }

    /// Control: a recorded binding that is not stale schedules nothing.
    #[test]
    fn pg770_bridge_leaves_a_consumer_without_a_stale_binding() {
        let root = pg770_root("portage-bridge-pg770-b", "dev-libs/p569prov\n");

        assert!(!pg770_reinstalls(&result, "p569virt"), "{:?}", pg34_plan(&result));

/// The installed packages the solve walked below a package the plan merges:
/// every `AlreadyInstalled` entry reachable from a merge-bound entry along the
/// solution's dependency edges, installed-to-installed edges included.
fn bridge_walked_installed(
    entries: &[GraphEntry],
    parents: &HashMap<String, Vec<(String, String)>>,
) -> HashSet<(String, String)> {
    let mut children: HashMap<String, Vec<String>> = HashMap::new();
    for (parent, child) in solution_taken_edges(parents) {
        children.entry(parent).or_default().push(child);
    }
    let kept: HashSet<String> = entries
        .iter()
        .filter(|e| matches!(e.outcome, PretendOutcome::AlreadyInstalled { .. }))
        .map(|e| format!("{}/{}", e.category, e.package))
        .collect();
    let mut stack: Vec<String> = entries
        .iter()
        .filter(|e| super::merge_bound_version(&e.outcome).is_some())
        .map(|e| format!("{}/{}", e.category, e.package))
        .collect();
    let mut seen: HashSet<String> = stack.iter().cloned().collect();
    let mut walked = HashSet::new();
    while let Some(cp) = stack.pop() {
        for child in children.get(&cp).into_iter().flatten() {
            if !seen.insert(child.clone()) {
                continue;
            }
            if kept.contains(child)
                && let Some((category, package)) = child.split_once('/')
            {
                walked.insert((category.to_string(), package.to_string()));
            }
            stack.push(child.clone());
        }
    }
    walked
}
