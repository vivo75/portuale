# L0 resolver-parity atom list.
#
# One atom (or set) per line; blank lines and `#` comments ignored.
# `TEST/layers/l0/in-container.sh` runs `emerge -pv --color=n <line>` with
# both real portage and portuale for every entry and
# `TEST/compare/resolve-compare.py` diffs the merge lists + errors + exit
# codes. Curated for breadth of resolver machinery, not for a specific
# bug -- keep it that way; edge-case reproducers belong in `fixtures/`
# and the `porttest` overlay.
#
# Entries are chosen to be present in the pinned 2026-08-23 gentoo tree.
# If a line stops resolving under *both* PMs (tree moved, package gone),
# fix or drop the line -- a line that only one PM can resolve is exactly
# what L0 exists to catch, so do not drop those.
