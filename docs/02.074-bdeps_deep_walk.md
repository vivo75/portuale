## 2. Portuale today

- `enqueue_dependencies` (the `AlreadyInstalled` recursion) walks the
  installed parent's `*DEPEND` (effective view by default) with the
  installed `USE`, and its `||` selection goes through the shared
  `disjunction_preference` / `promote_tied_alternative`. Build-time
  keys are marked `optional` in `merge_order::key_priority(key, built)`
  but the walk does not otherwise distinguish an optional dep.
- `disjunction_preference` returns `AltPreference::Installed` when
  `all_available && all_use_satisfied && atoms.iter().all(atom_cp_installed)`
  -- cp-level, so an alternative whose *slot* is not installed can still
  rank in bin 0; `atom_matches_installed` (version/slot/USE-aware) is
  only used in the `!all_available` "other_*" path. `want_update` is a
  documented cut (pinned `false`) in `promote_tied_alternative`.
- The finding's current attribution is "the disjunction preference lands
  on the uninstalled alternative", but **S0 must verify that** against
  `--json`/`--debug` rather than assume it.

## 8. Risks

- **Host-only reproducibility.** The classes depend on this host's
  installed world; S0 must land fixture repros or the fix cannot be
  regression-tested. If a class cannot be reduced to a fixture, say so
  in the findings and pin the host probe output as the evidence.
- **Preference swings.** Changing `disjunction_preference` ranks touches
  every `||` in the tree; the upstream-oracle `test_or_choices.py` cases
  (`TEST/logs/r4-20260915/`) and the `||` contract suite are the guard.
  Keep the change behind the S0-confirmed condition.
- **Walk depth.** A broader installed-parent walk can pull large
  subtrees into unrelated resolves. Measure the L0 host run
  (`-puDvN @world`) before/after for both package set and wall clock;
  a set that matches real but takes minutes more is still a regression.
- **Slot-op coupling.** The #65 S2 `walked` gate consumes `entries`; a
  changed walk can silently change the build-time slot-op set. The
  fixture-oracle bed with `FX_SLOTOP_BDEP=1` must stay green.
