## 0. Rules for this phase

- **Test-only: no product byte.** Every change lands in
  `merge_order.rs`'s `mod tests`, or in test-only helpers inside that
  module. If a test can only be written by changing the function under
  test, or a test reveals a real bug, **STOP and file it** with the next
  free number (batch §0 addition 4) — this phase does not fix bugs.
- **The mutant list is the oracle.** Every mutant listed in #144–#146
  ends *caught*, or classified *equivalent* / *trace-only* with a
  one-line reason in `mutants.md`. A cluster that ends with more than a
  handful of unclassified survivors stays `DONE-PARTIAL` with the list.
- **No new seam.** #145's installed half prefers an existing
  `fixtures/var/db/pkg` entry (there are 112 fixture vdb entries, several
  with `*DEPEND` files); a seam is a product change → STOP.
- **No bed, no pmtest pin, no corpus.** `cargo test --release` plus the
  usual fmt/clippy. The only pmtest change is the `mutants.md` finding
  (batch §4 Phase 8).
- **Timeouts are classified, not pinned around.** Per #144: inspect each
  timeout mutant and say whether a bounded-iteration test can observe it,
  or whether only the timeout kills it (then it is recorded *caught by
  timeout*).
- **Session rule while the Phase 7a `l3-core` campaign is live:** run
  every cargo command with
  `CARGO_TARGET_DIR=/home/vivo/repo/PORTUALE/.p8-target`. The campaign's
  container mounts `rust/target/release` read-only at `/usr/local/bin`
  and executes `portuale` from there; rebuilding into `rust/target`
  mid-run would swap the binary under test. Also: do not edit any `.sh`
  under `../pmtest/differential-test-bed/` while
  `pgrep -af l3-source-parity` matches (batch §4 Phase 7a).
- The line numbers in `mutants.md`'s 2026-09-22 triage have drifted (the
  file grew from 3199 to 4324 lines across Phases 5/5b/6/6b); S0's
  re-run names are the current authority. Find code by symbol name.

**#146 after S1** (three `--iterate` passes, only previously-missed
re-tested): **156 caught / 6 missed / 6 unviable**. The six survivors
are classified equivalent in `mutants.md`:

- `split_disjunctive` :175/:176 (`&&`→`||`) — the mutated condition can
  only differ when a `(` deeper than `aod+1` is reached with
  `branch_group_depth` still `None`; well-nested structured-reduce
  output always sets it at `aod+1` first. Unreachable.
- `frontier_enabled -> true|false` — the frontier is a pure performance
  layer; `frontier_matches_direct_scans_*` and
  `disabled_path_matches_direct_scans` pin both arms to identical leaf
  sets and order, so forcing either arm is behavior-neutral.
- `build_digraph` :2012 (`||`→`&&`) — at the uninstall reverse-edge
  loop `g.children[owner]` can never hold the removal node (the forward
  walk's `match_candidates` drops every `Uninstall` target), so the
  `any(...)` term is constantly false and the condition reduces to
  `i == j`.
- `build_digraph` :2025 (delete `satisfied` field) — the reverse edge
  sets `satisfied: false`, which is already `DepPriority::default()`'s
  value.

**#145 after S2** (`--iterate`, 47 mutants, then a final-tree pass):

## S1 (#146) — dep-key / priority mapping unit tests

**Targets (backlog #146).** `key_priority` (5: whole `RDEPEND|IDEPEND`
and `PDEPEND` arms deletable), `dep_edges_from_metadata` (5: all four key
arms), the ignore-priority ladder (`n_ignore_*`/`s_ignore_*` constant-RET
replacements + in-body flips + `PriorityRange::ig` RET +
`DepPriority::fmt` whole-body), dep-target ranking (`rank_best` 6 with 0
caught; `select_dep_target` 5), `split_disjunctive` branch bookkeeping
(17), `build_digraph` required_by-fallback + self-edge arms (13),
`frontier_enabled -> true` (1).

**Tests to add (predicate level over synthetic values, no graph):**

- `key_priority_pins_each_dep_key_ladder` — `key_priority` for
  `RDEPEND`/`IDEPEND`/`PDEPEND`/`DEPEND`/`BDEPEND`, both `built` values:
  asserts the exact field set (runtime; runtime_post; buildtime +
  `optional == built`).
- `dep_edges_from_metadata_pins_key_order_and_priority` — one metadata
  map with all five keys (same atom in two keys stays two edges, key
  indices 0..4, cross-key token order cannot leak, blocker atoms
  dropped, unparseable tokens noted+dropped, `:=` promotes
  `buildtime_slot_op`/`runtime_slot_op`, `built` only flips `optional`).
- `split_disjunctive_pins_group_and_branch_bookkeeping` — token slices:
  bare inline atoms, one `||` with bare alternatives, nested `( … )`
  branches, a second `||` group, `virtual/*` deferred outside a group
  (`u32::MAX`), atoms after a group close back inline, depth/branch
  counters for interleaved groups.
- `ignore_predicates_pin_every_ladder_rung` — truth tables over
  `prio(word)` for all ten predicates, with the distinguishing rows for
  each sub-condition (optional, runtime_post, runtime_slot_op, buildtime,
  satisfied, buildtime_slot_op) called out so deleting any one term or
  flipping any connective changes an asserted row.
- `priority_ranges_pin_their_named_rungs` — `NORMAL`/`SATISFIED`
  `medium`, `medium_soft`, `medium_post` indices resolve to the intended
  predicates (behavioral comparison over all words, not pointer
  equality), and `ig(i)` for every ladder index.
- `dep_priority_display_pins_the_classification` — `format!("{}", p)`
  for one priority of each class.
- `rank_best_prefers_merge_bound_then_vercmp` / `select_dep_target_*` —
  synthetic entries: merge-bound beats installed, vercmp beats string
  order, ties keep first, NVC entries neither eliminate nor are
  eliminated, `merge_bound_only` drops installed/self targets.
- `build_digraph_*` — required_by fallback edge added only when no
  forward edge exists (and not when a sibling slot edge already
  resolves), self-edge dropped unless unsatisfied buildtime, Uninstall
  reverse edge (owner is the removal's child), `frontier_enabled`
  fallback.

**Stop rule:** a #146 mutant that needs product code to become
observable is a finding, not a test.
