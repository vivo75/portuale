### P19 — #153: the `invalid` mask for a conditional outside the package's own IUSE

**How real does it** (H0 item 3):
- `Package._validate_deps` runs at package construction.
  `use_reduce(..., matchall=True, is_valid_flag=self.iuse.is_valid_flag)`
  covers both `flag? ( … )` groups and `[flag?]`/`[!flag?]`/
  `[flag=]`/`[!flag=]` use-dep conditionals.
- On failure, `_metadata_exception(k, e)` records an invalid-metadata
  mask. The all-masked report then renders
  `masked by: invalid: DEPEND: USE flag 'x' referenced in conditional
  'x?' in atom '…' is not in IUSE`.
- **Skipped for installed packages** (`dep_valid_flag = None` when
  `self.installed`). `is_valid_flag` uses the **effective** IUSE,
