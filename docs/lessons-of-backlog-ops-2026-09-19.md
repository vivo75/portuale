# Lessons from backlog ops 2026-09-19 — agent dense notes

> **READ-ONLY — LLM AGENTS ONLY. DO NOT EDIT THIS FILE.**
> Companion to the `recap-of-backlog-ops-*.md` indexes (those track
> per-item status/residue/cuts). This file tracks *how to work* so
> future implementations — and ports of future Portage versions —
> don't re-pay the same tuition. One idea per bullet, densest form.
> No history, no mechanism detail, no per-item narrative.

## Finding truth about real Portage

- Run it, don't read it: translating an upstream `ResolverPlayground`
  case into a fixture and diffing beats reasoning from `depgraph.py` —
  three items misread the source first.
- Capture `--debug` merged (`PYTHONUNBUFFERED=1 ... >log 2>&1`);
  separate streams hid walk/solver/dump ordering and produced a wrong
  theory that cost two implementation attempts.
- Pin `PYTHONHASHSEED=0` (set-order wobble is real, not flakiness);
  point `PORTAGE_GNUPGHOME` at a writable `chmod 700` keyring copy or
  nothing runs.
- A test file may rebind `test_cases` right before the consuming loop
  — verify what actually executes before citing "upstream proves".
- Host probes always `-p`, confirmed on two consecutive runs before
  becoming a claim; `-e` + `--usepkg=n` for a genuine rebuild;
  determinism blocks go in resolved config (`make.conf`), never the
  calling shell's env (silently different settings, identical CLI).
- Oracle binaries must be real-built (`--buildpkgonly` + `--usepkgonly`
  pipeline); crafted archives are rejected by real and prove nothing.
- Bed staging lies: `ROOT=$FX` splits cascades across two roots — a
  whole item was an artifact; the host-exact control (`ROOT=/`) is
  mandatory before any code. A partial run is not a parity run: mark
  `partial`, keep the log, never diff it.
- Real disagrees with itself (parallel-`estrip` race, hash-seeded
  sets): one allowlist row, never chased to zero. Compiled-payload
  bytes never gate except hand-written fixtures.

## Before writing code

- S0 oracle matrix first, code second; a contradicting cell means
  stop, not reinterpret. S0 commits hold probes only, zero product
  code.
- Time-box investigations (owner-fixed, e.g. 2–4h); expiry without a
  reproduction is a documented cut with the matrix attached, never a
  guessed fix. Fifteen negative probes are a result: file what it is
  NOT, with the excluding probe named per rejected rule.
- Never implement against a symptom fixed elsewhere: re-diff the host
  after every neighboring landing — two items evaporated that way
  (options mismatch, staging artifact).
- Require the `--debug` markers before touching code (e.g. all three
  cascade markers); absent markers mean the wrong family — stop.
- First-draft unconditional rules are usually wrong (unconditional
  bdeps drop, runtime gate, never-walk-bdeps): find the real probe
  that contradicts the draft before coding, not after.

## Reading real source (also for future Portage versions)

- The cited line is often the wrong branch: the gap was the
  early-return branch bypassing the tracked structure, not the
  tracking code. Read callers + early exits, not just the named
  function.
- Real auto-enables modes in more places than any backlog text says
  (complete mode on ver/USE/slot, not just the conflict path). Grep
  all writers before porting a predicate.
- Distinguish same-named things: `identical_binary` (installed
  candidate) vs the binary skip; unfiltered `forced_flags` vs the
  `retain(iuse)` variant; cp-level vs atom-level installed match;
  `optional` matters only when no child is selectable.
- Port intent, not literal shape: xpak paths → gpkg flat
  `metadata/<KEY>`; `FILE`=basename vs `.__download__` temp;
  `DIGESTS` sorted; error classes (`Invalid` skip vs `Fatal` abort —
  all xpak errors are `Fatal`).
- Real `varexpand` has no env (`\$` literal); POSIX `shlex` unescapes
  only `\"`/`\\` inside quotes. Test parsers through `resolve_config`
  + live `portage.settings`, never hand-built structs (hid a bug for
  a full slice).
- `get_pregenerated_cache` takes the first format only; empty layout
  means auto (`md5-dict` then `pms`); lowercase + split before
  comparing anything from `layout.conf`.
- Shared on-disk formats must round-trip both directions (real reads
  portuale's output and vice versa) — verify live, not by schema.
  Where every candidate is digest-verified, deterministic order
  replaces real's shuffle as a documented cut, correctness-neutral.

## Scope and process discipline

- One slice, one commit, no squash; paired across repos (product
  here, fixtures/pins/bless in pmtest, messages quote each other).
  Commits are never pre-authorized — the plan carries the clause.
- Backlog numbers are never reused: scan *all* tiers first — two
  items claimed #58 thirteen minutes apart.
- Drops are owner decisions with names, not silence; rejected
  narrowings stay rejected — reintroduce only with new oracle
  evidence citing the excluding probe.
- Order matters (USE-fold before binpkg gate; probe-ordering before
  display). Re-scoping to a bed-fix with no product code is a valid
  outcome when S0 STOPs. File the split halves (display vs
  scheduling, gate vs fix) as separate numbered items immediately.
- Before writing "does not model", grep portuale (the helper
  usually exists behind a gate). Enumerate feedback/enum variants
  explicitly. Oracle cells need per-cpv granularity. Re-run L0 after
  touching resolver/merge code, recording mtime + HEAD. Corpus bless
  rides only in the pmtest commit after line-by-line drift review.
- Name a shared-mechanism link both ways from the start; one fix
  closes both residues or evidence splits them. A later slice that
  supersedes a DONE must amend that DONE entry — never two truths.

## Display vs mechanism

- Satisfied rows print inline, unsatisfied rows trail; flat and tree
  are different serializers (greedy leaf pop off in tree) — never
  unify their predicates by deletion.
- Counters exclude uninstalls; nondeterministic values (timing) ride
  `--json` only, never stdout; no wildcard arm on large enums (~500
  match sites).
- Tree edges need the `merge_bound_only` split from the scheduler
  digraph; the cp-keyed `required_by` fallback misattributes slots —
  skip owners whose own atom resolved to another instance.
- Hoist per walk, not per list (list-level hoisting regressed
  12.4s→15.8s). Cheap exact guards first (no-`!` skip, no-merge-bound
  early return, `HashSet` walked set). A faithful single-file read
  beat the clever skip (0.99s→0.83s). Profile the `-p nano` shape
  before optimizing.

## Fixture and pin hygiene

- Committed fixtures declare minimal features so existing pins stay
  byte-identical; host shapes reproduce via copied configroot, never
  production-fixture edits.
- New fixtures need real md5s + md5-cache entries + `git add` before
  any `git clean` (clean deletes untracked fixtures). Backquote in
  `DESCRIPTION` fails the depend phase on both PMs.
- Pin both ways (withholding shape + updating twin). Strict-xfail
  XPASS fails the suite — convert to a pin on first XPASS.
- Crafted hostile archives are scratch-only and must error, never
  skip-and-win; device cells need passwordless sudo; keep the
  decompressor a subprocess piped into the in-process reader.
