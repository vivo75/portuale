## S1 (#50) — emit the first fixture batches (repeat until the ratio stops paying)

**State today:** `scripts/upstream_resolver_translate.py` (in
`../pmtest/scripts/`) wraps the real `ResolverPlayground` and captures
the **executed** oracle, not the source literal. `--all` over the pinned
checkout gives **99 files / 1032 cases / 0 errors**. `--emit-fixtures`
writes ebuilds + md5-cache, installed vdb and world. **Bulk-emitted so
far: 0.** The ~34 hand-translated cases predate the tool.

From the 12-file sample: 4/32 playgrounds are ebuilds-only, 17 emit with
installed/world, 11 need per-batch `user_config` / `repo_configs` /
`profiles` / `binpkgs` mapping.

**One batch = one commit.** The loop, unchanged every time:

1. Pick the next batch of upstream test files. **Start with the
   ebuilds-only ones** — no `user_config`, no `binpkgs` — they are the
   4/32 class and need no mapping work.
   ```sh
   cd ../pmtest
   python3 scripts/upstream_resolver_translate.py --all --stats
   ```
   Use `--stats` to choose; record which files this batch covers.
2. Emit into a **scratch** directory first, never straight into
   `fixtures/`:
   ```sh
   python3 scripts/upstream_resolver_translate.py <modules…> \
     --emit-fixtures /tmp/claude-*/scratchpad/fx-batch-N \
     --json /tmp/claude-*/scratchpad/fx-batch-N.json
   ```
3. **Collision check before copying anything in.** Every emitted
   `cat/pkg` must not already exist in `fixtures/repo/`. A collision is
   a STOP: rename in the batch's own namespace or skip the case; never
   overwrite an existing fixture — other pins depend on it byte-for-byte.
4. Copy in, add the `metadata/md5-cache/` entries, `git add`.
5. Add one `CASES` entry per emitted case (Rust exit code; the output
   invariants in `pytests-contract-suite/test_output_invariants.py` then
   run over it automatically) and the pinned-output test functions. The
   pinned value is the **captured oracle** from step 2's JSON — real's
   executed result — not portuale's output.
6. Run the full pass. **Every case that diverges is a finding**, not a
   pin to adjust:
   - a real portuale bug → file it with a fresh number and suppress the
     cell with an `owner: portuale-bug` allowlist row citing that number;
   - a staging/wording artifact → allowlist row with the reason;
   - anything else → STOP and report.
7. Commit (when asked): `#50: bulk-translate upstream resolver batch N
   (<files>)`, body naming the files, the case count, and every finding.

**Stop rule for the whole slice:** stop emitting batches when a batch
yields **no new finding and no new coverage class** — the ratio has
stopped paying, and the remainder is recorded as a documented cut with
the running count, not ground through.

**Report the running count every batch**: `99 files / 1032 cases
captured, N bulk-emitted` — that number is what #50 tracks.

**Trap (`lessons-…` "Bed staging lies"):** the default staging splits
cascades across two roots (`ROOT=$FX`). A finding that only appears
under the split is a staging artifact until a host-exact control
(`ROOT=/`) reproduces it. A partial run is not a parity run: mark it
`partial`, keep the log, never diff it.
